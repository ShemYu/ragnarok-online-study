# Historical V1 prototype sprites

The placeholder novice and peach slime were drawn procedurally by
`scripts/actor_visual.gd`. The palette, silhouette, expression and animation
frames in this directory were authored for the first learning prototype.

These are preserved for before/after comparison. The current game uses
`scripts/ro_sprite_actor.gd` and the native reference files documented in
`assets/reference-ro/provenance.json`; the V1 actor is not the active renderer.

`sprite-contact-sheet.png` shows the former front/back/side character frames
and slime. `tests/actor_visual_check.gd` tests that historical implementation,
not the revision 2 runtime.
