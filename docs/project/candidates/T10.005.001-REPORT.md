## API

`apply_shared_trial_clock(sources)` takes exactly a `dict` with `parent`/`proxy`/`launcher` `bytes`
values. It returns the same three keys with patched bytes. The order of work is:

1. Check types and keys (`TypeError`). `bytearray`, `memoryview`, `str` and `None` values are refused.
2. Verify all three size/SHA-256 pins before doing any edit (`ValueError`).
3. Check each surface: no existing `trial_now`/`clock_gettime`/`CLOCK_UPTIME_RAW` (this refuses
   already-patched input); exact call counts of 11/11/21; exactly one `\ndef need(` and one
   `def need(`; the transfer token appears 0/1/0 times.
4. Apply the edits, then check the result: the prefix before the anchor is unchanged, no old
   calls remain, growth is greater than 0 and at most 2048 B, and an **exact inverse** gives back
   the input bytes. Any failure raises an error, so a result is never partial.

The patch uses no filesystem, process or network access and does not import or execute the
supplied sources. It imports only `hashlib`.

`023c320066541aefae6676a45c0899d1b95ec60dd2071f4eb999d6001803ec02`. It ends `    return now\n\n`.

```python
def trial_now():
    need(callable(getattr(time,'clock_gettime',None)) and type(getattr(time,'CLOCK_UPTIME_RAW',None)) is int,'trial uptime clock unavailable')
    try:now=time.clock_gettime(time.CLOCK_UPTIME_RAW)
    except OSError:now=None
    need(type(now) is float and math.isfinite(now) and now>=0,'trial uptime clock invalid read')
    return now
```
