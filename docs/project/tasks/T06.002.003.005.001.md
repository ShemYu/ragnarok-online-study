## Framing, opaque subset and declared projection

Read/hash both full sources before classification. Build LF/offset indexes once; no repeated rescans from file start per event. A cursor on LF belongs to the preceding physical line. Physical-line and event partitions are independent and each conserves every byte. Do not strip comments inside static fields or split opaque interiors into top-level events.

Global preflight initial UTF8 BOM, any NUL or bare CR (CR not immediately followed by LF) emits one whole-file suffix from0, diagnosing the earliest hazard byte; the other source remains independent. NUL/bareCR refusal is authored policy, not native rejection.

At the next non-whitespace/comment byte, fewer than3TABs before the physical terminator gives malformed_columns from that header. Otherwise first3TABs delimit w1..w4; w4 is the entire remaining physical payload. Exact ASCII-case-insensitive w2 monster/boss_monster admits static. Any column>2047bytes stops framing with column_width; never imitate native truncation.

Opaque admits only exact w1 "-", exact case-insensitive w2 script, w3 ASCII `[A-Za-z_][A-Za-z0-9_]{0,48}`, and w4 starting exactly "-1,{" on that physical line. Opener is that fixed prefix's brace, depth initially1. Header ends before it; body/close ownership is as above. Ignore braces inside double-quoted strings and // or nonnested /* */ comments. In a quoted string, backslash skips the following byte only when its preceding raw byte is<=0x7e, following the pinned rule; use no Unicode heuristic. Escaped LF/EOF is an authored escape_boundary, unescaped LF is string_linebreak. Missing string/comment/brace termination stops certification, not compilation. Other mapped/function/state/shop/warp/duplicate/mapflag/unknown headers give unsupported_construct. The illustrative bytes `H{/*}*/x}` are malformed_columns from0, not an admitted opaque header. No script compilation, label/command extraction or language validation.

Supported projection requires:

- **w1:** exactly1/3/5comma tokens: map; map,x,y; map,x,y,xs,ys. Map is ASCII `[A-Za-z0-9_]{1,11}` with optional case-insensitive .gat suffix, total<=15bytes; preserve literal bytes. Supplied coordinates/spans are whole canonical signed decimal int16,<=6bytes each.
- **w3:** one nonempty raw token<=23bytes without comma/TAB/CR/LF/NUL. Raw non-ASCII is allowed; no character count, decode, padding, level syntax or truncation.
- **w4 structure:**2..5comma tokens with no TAB. Preserve empty tokens. Structural cardinality/TAB failures are w4_form; otherwise emptiness belongs to the relevant component form. Six+tokens is w4_form before component checks.
- **sprite:** canonical unsigned decimal0..2147483647,<=23bytes. No Aegis/hex/octal/sign/partial-conversion inference.
- **amount:** canonical signed decimal int32,<=11bytes including sign. Preserve0/negative/>1000 as declarations, without native accepted-range conclusions.
- **delay/variance:** canonical unsigned decimal0..2147483647,<=11bytes each. Omission alone defaults delay5000/variance0.
- **event:** nonempty1..76rawbytes, no comma/TAB/CR/LF/NUL. Literal quotes are ordinary bytes, not CSV. Omission alone means absent; explicit empty is event_form.77+bytes stays unsupported rather than emulating an unsafe native boundary. A fifth token1 is event hex31, including under boss_monster.

Canonical signed decimal is0 or optional minus followed by a nonzero digit then digits; unsigned is0 or nonzero digit then digits. Reject plus, whitespace, leading zeros, -0, partial conversions and overlong tokens before unbounded integer conversion. Missing coordinate pairs/spans default0. Empty present coordinate/component tokens are gaps, never defaults. First-gap order is map_form,name_form,w4_form,sprite_form,amount_form,delay_form,variance_form,event_form. For example an explicit empty final delay is delay_form at its zero-length token, not w4_form.

Native membership/storage/clone/map gates, size/AI/level/config/rate transformations, registration, RNG/free-cell selection, dynamic caching and script effects remain excluded. Values are declared/source defaults, never effective state.
