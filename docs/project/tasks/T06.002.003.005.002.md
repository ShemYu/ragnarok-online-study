MapReference is exactly:

```text
{raw_hex:string, normalised:string,

```

Require even-length lowercase hexadecimal without whitespace, then decode the
supported map-slot hex to ASCII. Its raw grammar is
`[A-Za-z0-9_]{1,11}` plus optional case-insensitive `.gat`, at most15bytes.
Apply **one** mapindex_getmapname operation: remove one terminal case-insensitive
`.gat`, retain base case, otherwise retain bytes. This subset never needs further
clipping. No trim, base lowercasing, aliases, Unicode/filesystem guesses or
expansion to unsupported double suffixes. `normalise_map` returns that ASCII
string. Lookup uses the exact final `index.state.reverse` name, never forward
slots, index events, a synthesized table or a candidate's name.

Absent name gives missing/null; stored0 gives zero/0. Both have empty candidates
and candidate_state`not_applicable`. Nonzero gives nonzero/id and **all** map
candidates whose precomputed index_lookup.id equals it, in original ordinal
order. Empty match gives candidate_state`none`; otherwise`present`. Copy entire
original candidate objects, including attempts, disposition, cache/slot,
duplicate reference/reasons/uncertainty. Never filter to retained, normalize
candidate names again or collect null-ID candidates by null equality. Configured
raw`Foo.gat.gat` can already have name`Foo.gat` and lookup`Foo`; its original
object legitimately attaches to spawn`Foo` by numeric ID. That double-suffix
token itself is outside the raw spawn subset.

