## Pure core contract

buildCatalog(input) performs no I/O and does not mutate callers. Its input is
ordinary finite JSON data with these six fields:

- roots: full original manifest roots, ordinal equals array index, including
  all edge metadata; remaining_gap_root_ordinals and prior_first_level_gaps
  carry the full original gap values. Gap ordinals exactly follow roots whose
  rsw edge has job_id null. Other edge kinds stay unchanged, not model sources.
- first_level_model_jobs: every .004 catalog job with kind=rsw/role=model in
  original order, all original fields unchanged, with source_job_index set to
  its ORIGINAL catalog.jobs index. That index can be sparse; it is not this
  filtered array's position. Synthetic inputs contain the required join fields
  only. An optional occurrence_summary_pointer must equal
  /summary/model_dependencies; absence has that same default.
- model_targets: full original manifest.targets, not report-added outcome rows.
  model_ordinal equals array index; original target_index is a different domain
  and may equal model_ordinal on some rows. Preserve every opaque nested field.
- model_rows: all complete .006 JSONL records in physical order, as an array.
  Every unique id/job_id agrees, kind=model, bytes/nonempty64hex SHA/header
  metadata are valid and every target links to one row with the same bytes/SHA.
  Header is a12lowercase-hex observation, not a format/version allowlist.

All constructor rows must be worker_started=true and have exact cleanup
{exit_observed:true,exit_code:0,terminated_by_parent:false}. Only returned/true
with a summary, or constructor_exception/false with a constructor exception
and no summary, are admitted. No omitted/missing/duplicate/orphan job/target.
Every row has at least one target. Preserve exception objects completely;
constructor exceptions have unknown tables, not zero textures.

Validate the complete parent bijection. Every target referrer is role=model
and joins source_job_index plus loader_index to the exact original loader
entry; entry.index equals its position, target_index/http_path agree, and no
source entry/referrer is lost or duplicated. Source model jobs have unique IDs
and indexes. Their ordered root_references exactly match original rsw edges.
occurrence_loader_indexes contains only in-range integer indexes, first new
indexes appear0,1,..., and every loader entry is used. Preserve every occurrence;
its placement ordinal is the RSW MODEL ARRAY index, not mixed-record position.
source_name_pointer is /summary/model_dependencies/<first occurrence>/filename.
Validate original model stages using data\model\ prefix/whole-name trim/slash
encoding; NEVER reconstruct a model name by percent-decoding a target path.

Returned summaries retain all final global texture slots, duplicates and
unused slots. Validate texture_declarations against summary.textures, exact
index and /textures/<index> pointer. Preserve all six common fields unchanged:
texture_index,constructor_pointer,raw_name,logical_name,filemanager_name,http_path.

- roots, remaining_gap_root_ordinals, prior_first_level_gaps and model_targets

- model_parent_links: target order then original referrer order. Copy full
  referrer/loader_entry/root_references, source_job_id and catalog_target_index;
  placement_indexes and /summary/model_dependencies/<ordinal> pointers retain
  every matching occurrence in original order. Do not expand root combinations.

  fields shown in the fixture; derive ordered target_model_ordinals. Returned
  exception=null; copy global numeric_fields and the six projected node fields
  node_index/textures/texture_references/face_count/keyframe_counts/numeric_fields.

  node_links[{node_index,slot_index}]. Exception animation/numeric/nodes/
  declarations are null; returned empty nodes/declarations remain arrays.
  Original full transforms/boxes remain in the pinned source row at /summary;
  source_row_index identifies that JSONL row. Do not claim they were copied.
- nested_targets: first appearance in job/table order, exact http_path string
  as the only dedup key, with index/http_path and every ordered
  referrer[{job_index,texture_index}]. Shared model bodies do not merge parents.
- limits: exact six profile.limitations strings. No actual GET prediction.
- counts: exact fixture/profile keys. Job outcomes/empty/nonempty/animation and
  node-slot counts are per constructor job. global_declarations sums returned
  table lengths; target_expanded_declarations multiplies each length by that
  job's target count. model_parent_links equals all target referrer counts;
  model_placement_occurrences sums per-parent placement lengths;
  root_expanded_model_placements sums placement length times parent root count.
  No declaration-by-placement Cartesian product. Unknown exception tables
  contribute no observed declarations and remain explicitly unknown.
