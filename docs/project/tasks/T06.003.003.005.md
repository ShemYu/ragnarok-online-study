## Shared functions used by the production path

Expose these names so root can run the same finite controls on both candidates.
The authored fixture fixes complete typed results and literal hashes.

- `wire_target(http_path)` returns slash plus the unchanged encoded ASCII path.
  Refuse empty/non-ASCII/control/space, literal query/fragment/backslash,
  leading/trailing/repeated slash, literal dot/dotdot segments, malformed
  escapes or characters outside the fixture.additional_policy segment set.
  Raise ValueError with generic no-echo text. Preserve escape/case spelling;
  do not decode escapes, normalize or re-encode. This observes exact literal
  HTTP targets, not browser URL normalization equivalence.
- `write_all(fd,data,write_fn=None)` uses write_fn(fd,bytes-like), default
  os.write, until all bytes are physically written. Progress must be int
  excluding bool in1..remaining. Zero/invalid/overlarge progress raises OSError
  without retry; EINTR may retry. The caller still owns the descriptor.
- `transfer(response,fd,*,body_cap,aggregate_left,deadline,clock=None,write_fn=None)`
  returns exactly `{outcome,bytes,response_complete,complete_sha256,
  partial_sha256,late}`. Use monotonic by default. response.length is remaining
  framed bytes or null; response.read1(n) returns at most n and updates length.
  Reads are at most64KiB and never exceed either remaining byte budget. Order:
  known framing zero, declared over body cap, deadline, aggregate exhausted,
  body cap exhausted, then read. No extra byte/EOF probe at an unframed cap.
  Outcomes complete/declared_over_cap/cap_unresolved_eof/aggregate_cap/deadline/
  transport_error follow the golden. Framed truncation/read exception is
  transport_error. Hash/count fully stored chunks; complete hash only for
  complete, partial hash only otherwise, including SHA(empty). Every return
  sets late from final clock()>=deadline; a late final framed read stays
  complete. Storage exceptions propagate OSError with no transfer result;
  the production caller retains received-byte accounting and uncertain partial
  storage, closes owned resources and halts. Do not turn write faults into
  transport results. Reject invalid argument shapes/limits with ValueError.
- `inspect_signature(kind,prefix)` returns exactly `{state,prefix_hex}`.
  Model needs6bytes and GRSM or GRSX, BMP needs2and BM, JPEG needs2and FFD8.
  Below minimum is short; otherwise match/mismatch. Keep first minimum bytes.
  No extension/magic pairing or version allowlist. Prefix match is not parsing.
