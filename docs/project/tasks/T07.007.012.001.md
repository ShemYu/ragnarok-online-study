`pub fn read_ordered_archives(state: &std::path::Path, data_anchor: &std::path::Path, optional_archive_slots_present: bool) -> Result<Option<Vec<std::path::PathBuf>>, String>`

Read state/asset-archives.list without creating/writing any input or output.
Absent list returns Ok(None), preserving legacy slot behavior even when optional
slots are present. Present list plus optional_archive_slots_present=true refuses;
never merge it with the old slots. All other present-list failures return Err.

Manifest is an ordinary, unlinked regular file, at most65,536bytes. Admit its
complete bounded bytes and stable opened-FD/current-path identity using finite
before/after checks; reject static symlink/hardlink/nonregular entries and
changes during read. No arbitrary mutation-and-restoration/race-free guarantee
is required. Use std only; no platform flag guesses or dependency additions.

Grammar: strict UTF-8; exactly FIVE nonempty absolute paths, one per LF line,
including a single terminal LF. No CR, NUL, comment/blank lines, leading or
trailing whitespace. Internal spaces are valid. Refuse truncation/extra lines/
malformed encoding instead of trimming or silently dropping paths. Canonicalize
each entry, require readable ordinary files, preserve supplied order exactly
and reject duplicate canonical paths. Canonical data_anchor must occur exactly
once. Path identity and actual archive bytes/hashes/format/winners will be
admitted by ROOT later; do not parse archive bodies or require extensions.
Return canonical PathBufs in the same order. No alternate order, basename
special cases, geometry changes or archive flattening.
