## One small shared API

Python3.9-compatible standard library class `TransportCapture()`:

`record(kind, connection=None, **primitive_fields) -> bool`

`finish() -> bounded strict-JSON-ready dict`

Use exactly the eight event kinds/fields/state/result shape in the output
contract: listener_ready, accept, accept_error, request, native, handler_error,
log_error, close. One bounded in-memory event list with attempted sequence and
genuine monotonic elapsed_ns; no output/file/network/process operations in the
module or import side effects. Import json/time/copy stdlib if useful; no runtime
or acquired source imports. No parser, socket calls, callbacks or hook wrappers.

`connection` is an opaque socket OBJECT, never a descriptor number. Allocate
monotonic ids after accepted-object observation; compare identity only and hold
a reference only while active. Never call its attrs/fileno/hash/equality/repr or
close. A fresh object whose fd number happens to be reused gets a different id.
Removing active association after terminal close must not alias later objects.
Unknown connection, duplicate active accept/request/close/native index, invalid
schema/order/type are explicit observer rejection, not a guessed association.

A close with confirmed=False is a truthful incomplete observation, not proof
of physical closure. A socket accepted then closed without GET/POST entry is a
valid unknown/unrouted connection. Accept errors allocate no id. Handler/log
errors can be recorded without assuming command/path/request_version exists.
Record only bounded supplied primitive fields, never headers/body/raw error
args/nonces. Transport errors are observations, not automatic observer failures.

Native events identify the actual upstream row_index/wire as supplied later by
ROOT. They do not verify the row/body/send/worker outcome. An associated native
event needs prior GET. Direct health/cache rows explicitly use connection=None;
no all-upstream-to-browser invariant. Do not infer a URL for unrouted sockets or
identify the old missing browser request from aggregate accept counts.

Hard limits:8192rows and **entire final serialized dict <=1048576bytes**, measured
with the exact compact ensure_ascii/allow_nan=False convention in contract.
No configurable policy knobs. Reject/mark incomplete on cap or observer fault;
retain bounded honest rows/counters, never silent drop/success. No truncated
path is an exact join. Reserve envelope headroom so finish itself remains
bounded. finish seals, releases active references after snapshotting unresolved
counts and returns independent deep copies on every call; post-finish record
returns False without changing sealed data. No physical cleanup is performed.
