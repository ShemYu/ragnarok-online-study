### Exact typed data and result

separators=(',',':'),allow_nan=False).encode('ascii'), with no newline. SHA256

number=["number",little-endian binary64 lowercase hex], bytes=["bytes",hex],
table=["table",[[T(key),T(value)],...]]. Numeric keys use Lua equality, coalescing
1/1.0 and signed zero; represent key zero with positive-zero binary64. Numeric
values preserve signed zero. Boolean and number keys remain distinct. Sort
table entries by C(T(key)) byte order. Nil assignments delete table keys.
Other key/value kinds, nonfinite values/keys and selected closures refuse.

- globals: sorted lowercase hex names of final non-nil globals, without values.
- root: global_hex for b'QuestInfoList', table_ordinal, row_count, sha256 of
