## Source rules and exact meaning

- `summary.model_dependencies[i]` is the model-array ordinal, with object_index=i,
  filename/nodename strings. It is not the original mixed RSW record index.
  MapLoader301–308 prefixes filename once with `data\\model\\` and exact-string
  deduplicates in first-occurrence order. Keep every placement through its index.
  Hook matching happens after the model read; do not remove hook-matched entries.
- GND summary.textures is already an exact unique table, in first-use order.
  texture_indexes maps original slots to it. Every index must be a nonnegative
  integer in range, each table entry used, first index appearances0,1,... and no
  duplicate table strings. Range checking alone is insufficient. Prefix each
  table entry once with `data\\texture\\` in existing table order; do not apply a
  second post-trim dedup. Loader queues each entry; only our target index compresses.
- FileManager388/201 applies `replace(/^\s+|\s+$/g,'')` to the whole prefixed
  filename. This is ECMAScript whitespace. Interior/prefix-separated whitespace
  survives; trailing whitespace can disappear. Do not use a broader trim set.
- FileManager246–257 replaces backslashes with slash, then
  `replace(/[^/]+/g, segment => encodeURIComponent(segment))`. This constructs a
  relative path before remoteClient or /client/ is prepended. Preserve case,
  repeated/empty slashes, dot segments, `!'()*` and JS UTF8 URI encoding.
  Do not decode existing escapes: `%` becomes `%25` (`%20` becomes `%2520`). No decoder, codec guess, path normalization, lowercasing,
  extension repair, alternative retry or alias is applied to these roles.
- HTTP is conditional after local fs/FileSystem/GRF fallbacks. A target entry is
  a constructed string, not evidence of a GET, browser URL resolution, archive
  winner, deduplicated runtime request, availability or format compatibility.
- Explicitly defer RSM/RSM2 parsing/embedded or mesh-used/animated textures,
  sounds/effects/hooks/STR/material recursion and water. Water requests need
  truthy compiled waterVertCount, unavailable from these constructor summaries.

The prefix notation above denotes a JS string with one backslash per separator.
