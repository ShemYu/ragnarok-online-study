1. **Identity and schemas.** The task is `T07.007.014.017`. The new schemas
   are:

   - result: `t07-014-017-nested-delivery-result-v1`
   - evidence: `t07-014-017-nested-delivery-evidence-v1`

   - profile: `t07-014-017-normal-nested-texture-preparation-v1`

   `SPEC` pins the profile at 8253357 B / `84bd3ed1…`. Runtime admission stays
   unbound.
2. **Bounds.** `BODY_CAP` is 8 MiB. `AGGREGATE_CAP` is 192 MiB of cumulative
   new HTTP bytes. For the remainder batch this starts at the Root-audited
   pilot bytes. These limits are unchanged: 64 KiB reads, 3 s per I/O, a 60 s
   batch and at most 2 s of settlement inside it. Target sampling now refuses
   files above 8 MiB instead of 1 MiB.
3. **Domain (`load_domain`).** The loader validates all 948 queries, 1546
   relations and 21 maps. For each query it:
   - requires role `texture`;
   - requires `lookup_full_query_observation.query` to equal the query, so the
     complete lookup observation is retained;
   - decodes the raw Latin1 bytes into the slash path, encodes it once per
     segment, then compares the result with `mapping.wire_target`,
     `query.wire_target`, `query.http_path` (no leading slash),
     `mapping.http_path_encoded_once`, `raw_request_latin1`, `latin1_name`
     and `slash_name`. It compares and never re-encodes;
   - requires `metadata_real_size_range_all` to equal the current range, and
     every size to be at most `BODY_CAP`;
   - requires `new_body_expected_sha256`, `new_body_observed_pin` and
     `archive_winner_proved=false` to be unset.

   Reuse rows must be exactly `SPEC['reuse']`. Each needs a complete
   `reuse_expected` with `no_new_GET=true`, and
   `normal_delivery_verified=true`. All other rows must have
   `reuse_expected=null` and `normal_delivery_verified=false`.

   The loader also checks:
   - extension counts for all rows and for the new rows;
   - reused, new and total bytes;
   - 438 non-ASCII rows;
   - case group `[[518,603]]`;
   - parentheses `[542,543]`, which must have distinct literal `(`/`)`
     wires;
   - ambiguous `[703]`, which must have two current candidates.

   The remainder is computed as the **new requests minus the pilot**. It is
   not computed as all rows minus the pilot. It must equal the profile's
   `batches.remainder_indices`, and the pilot must not intersect the reuse
   rows. Query objects and records are never altered or pruned.
4. **Per-row signature policy.** The exact case-sensitive suffix maps to the
   only admissible policy:

   | Suffix | Policy |
   |---|---|
   | `bmp`, `BMP` | `bmp` |
   | `tga`, `TGA` | `not_checked_tga` |

   Any other suffix (for example `.Bmp`) refuses. So does an unknown policy
   or a mismatched policy, such as a BMP row with `not_checked_tga`.
   `signature_state`:
   - `bmp` records `match` or `mismatch` from the `BM` prefix;
   - `not_checked_tga` always records the literal `not_checked_tga` and is
     never `match`;
   - an unknown policy records `unknown_policy`.

   Success requires `SIGNATURE_PASS[policy]`. TGA rows still need complete
   200/framing/EOF/length/stored-hash evidence.
5. **No replay of reuse rows.** Preflight refuses `reuse_replay` before any
   output or request if a selected batch contains a reuse row. The request
   loop repeats the check before each GET.
6. **Ledger and RESULT additions.** These are documented new fields; all
   closed key sets are still asserted:
   - Ledger `attempt_state` adds `reuse_only`. Those rows have
     `selected=false`, `observed=null` and materialization `not_observed`.
     `expected_pin` carries the prior bytes, SHA, qualified wire and source
     pointer, and `profile_record` keeps the full reuse provenance.
   - The ledger adds `signature_policy`, and evidence adds
     `signature_policy`.
   - `counts.reuse_only` is added.
   - RESULT adds:
     - `reuse_only_queries`
     - `casefold_alias_groups`
     - `parentheses_queries`
     - `signature_policy_claims`
     - `tga_consumer_checks_claimed=false`

   `archive_winner_claimed` remains false.

  does not observe the prior 1222 wires.

  identities (`shared_alias` on a case-insensitive volume, `matched_new`
  otherwise). Body or inode equality is not assumed.
- Query 703: delivery selects no archive winner.
- `not_checked_tga` is delivery-only. It makes no TGA magic, header, decode
  or consumer claim; that is a separate later gate.
- Observed new SHA values are observations, not independent oracles.
- The large-body fake uses the opt-in `steady` read described above. Real
  partial-read and `None` behavior over a socket is covered only by the
  protected suite's small-body controls and Root's later actual audit.
