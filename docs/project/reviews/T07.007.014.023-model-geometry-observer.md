## Interface (result/error shapes)

All errors are `ObserverRefusal{code}` before IO, or `ObserverFailure{code,stage}`
after IO. The detail text is in `message`.

- `preflightModel(body, placement, ground, limits)` returns a frozen
  `{version, animLen, shadeType, alpha, frameRatePerSecond, unused_global_names,
  volume_boxes, consumed_bytes, textures, nodes[...], resources{mesh_bytes,
  principal_typed_bytes, principal_typed_bytes_if32groups, smooth_face_visits,
  result_estimate_bytes}, placement, ground}`. Its refusal code is
  `preflight_refused`. Where the independent reader has an error label, the detail
  uses exactly that label.
- `extractSpans(source)` returns the five frozen `{id, LF_start, LF_end, offset,
  bytes, sha256, text}` regions.
- `buildScaffold(spans)` returns the authored `PRELUDE` followed by the exact
  122567 B of ordered region bytes.
- `compileInRealm(scaffold, body, placement, ground, limits, deadline, opts?)`
  returns `{preflight, copy_sha256, structure, textures, meshes[{node_index,
  texture_key, float_count, byte_length, float32_le_hex, sha256}],
  observed_emitted_bounds, timing}`. `opts` is used only for fault injection:
  `timeoutMs` (may only tighten), `heapStats` and `endianness`.
- `runObserver(options)` returns `{status:'PASS', dir, result{file, bytes, sha256},
  elapsed_ms}` or `{status:'FAIL', code, stage, dir, failure|failure_write_error}`.
- `main(argv)`: the only accepted form is `--actual --profile <abs>
  --private-prefix <abs>`. Any other argv, including no arguments, throws `usage`
  before any IO or write. The CLI prints `REFUSED` and exits with code 2.
- The extra exports are `validateProfile`, `validateInventory`,
  `validateBridge`, `checkStructure`, `buildCallScript`, `realmStats` (counts
  realm creations), `readHeldInput`, `writeExclusive` and the guards.

## Mechanism summary

- **Pins in source:** profile 5839/`1b80888a…`, source 624463/`1501ca10…`
  (19549 LFs), inventory 24463/`d6134039…`, fixture 148023/`c3ad8c64…`, closure
  122567/`a69e2472…`, the five region pins, the exact `FROZEN` model, query,
  map, group and placement indices, the body pin 19113/`3a84cdc3…`, the
  placement with negative zero restored at rotation[0], ground 200×200, the full
  expected static structure, the resource expectations 42876/73668/155748/438600
  and the fixed 19-key profile bounds.
- **Profile:** the schema is closed, with exact key order at every level. It
  requires canonical decimal C8 identities (`size` and `nlink=1` are checked),
  `profile_admits_execution:false` and fixed bounds that must equal the pins
  even when they are tighter. The tag `{"number":"-0"}` is accepted only at
  rotation lane 0, and every other object-valued scalar is refused. The
  formulas `Σ(120F+12V+12GV)`, `ΣG·V·F` and `Σ108F` are recomputed and must
  equal both the profile and `FROZEN`. All of this happens before the body is
  opened.
- **Inputs:** the profile, source, inventory and body are each read once
  through the donor's held-descriptor pattern: an `O_NOFOLLOW` regular file
  with a single link, BigInt C8 identities, pinned parent namespace, full SHA,
  short-read and extra-byte checks, and a literal identity recheck through
  publication. The pattern is reused unchanged and the donor file is not
  modified.
- **Source closure:** each line start is computed from the LF index. Each
  region must start at its pinned offset and end on whole LF lines, contain only
  ASCII, and match its SHA. The ordered concatenation must be 122567 B with SHA
  `a69e2472…`. The inventory's executable closure must match the region pins.
  Unused methods (`compileAtFrame`, `getStruct`, `readInt64` and the keyframe
  helpers) are retained. Provenance-only spans are absent from the scaffold.
- **Preflight:** this is a Node port of the Python reader, with the subset's own
  caps. It covers GRSM/GRSX 2.3 and checks every count before allocating, using
  Latin1 strings cut at the first NUL. Face length excludes its own length word.
  Accepted face sizes are 24, 28, 32, or 36–64 in steps of 4, and optional
  extras and leftover bytes are preserved. The other checks are:
  - indices are in range;
  - the primary group is in 0..31 and within the profile cap;
  - all four key counts are zero;
  - an optional volume count of zero may appear before exact EOF;
  - there are no trailing bytes;
  - all raw floats are finite with absolute value at most 1e6.

  The subset additionally requires shadeType 2, unique nonempty node names, no
  parented nodes, an exact identity mat3 using +0, and +0 offsets. Placement
  must be finite, at most 1e6, with nonzero scale. Ground values are integers
  from 0 to the cap. Typed, work, mesh and result budgets and a conservative
  overflow bound are checked before any realm exists. `compileInRealm` always
  re-runs this preflight first, even when it is given a stub.
- **Realm:** the context is created with `vm.createContext(DONT_CONTEXTIFY,
  {codeGeneration:{strings:false, wasm:false}})`. The prelude sets
  `var self = globalThis`, deletes `console` and verifies it is gone, checks that
  the realm is little-endian, and captures realm intrinsics such as the
  `TypedArray` toStringTag, length, offset and buffer getters, before any copied
  definition runs. `CodepageManager` and `Struct` remain unbound. The input
  `Uint8Array(len)` is created in the realm from a checked primitive. The host
  fills it with the captured `%TypedArray%.prototype.set`, then hashes the
  realm-owned copy and compares it with the body SHA. Placement and ground are
  built in the realm from validated numeric literals, with `-0` written
  literally. Position and scale are used once, with no second division by 5.
  The call script checks that the prototype and methods are not shadowed and
  reports the constructed structure. It then requires `hasAnimation()===false`,
  zero instances, an unchanged `createInstance`, one instance, and an unchanged
  `compile()`. `compileAtFrame` is never used and no transform or bounds repair
  is applied.
- **Bridge:** inside the realm, each mesh value must carry the intrinsic
  `Float32Array` brand, have offset 0, a backing buffer of exactly 4×length,
  length%9==0, finite lanes, and a total within the cap before any hex is
  built. The result is a single primitive JSON string. On the host,
  `typeof === 'string'` and the length cap are checked, and the closed shape is
  validated. The structure must equal the independent preflight; node 0's
  textures are compared as global keys after dedupe. Exact key order and float
  counts per node come from the preflight layout. All hex is lowercase, each
  lane is decoded and checked for finiteness, every byte is hashed, and the
  total must equal the preflight mesh bytes. No crypto is assumed in the realm.
- **Bounds:** `observed_emitted_bounds` come from the emitted mesh positions and
  are labelled as observed. All-vertex bounds stay an independent reference
  expectation. The local transformed `vert` array, which compile does not return,
  is not claimed.
- **Lifecycle:** reused from the donor: a fresh exclusive 0700 run directory and
  0600 files, a captured creation namespace, an exclusive pending candidate with
  full readback, a hard-link publication followed by resealing, and sticky
  failure or dequalification (a published alias is renamed to
  `result.unqualified.json`). Every input is closed and checked before PASS. An
  absolute deadline is checked around IO, realm work, copy, validation, hashing
  and publication, and also at the terminal point. Earlier captures are never
  overwritten or deleted. Failure evidence keeps full mesh hex when a compile
  returned, and never includes body bytes.

## Limits and unknowns

- **Not proven.** Mocked PASS results count only as lifecycle evidence.
  Authored tiny compiles do not prove the actual model702 bytes, the real
  geometry, rendering, gameplay, story or persistence, or that any of the 82
  functional resource gaps is resolved.
- **The finite external guard is the Perl `alarm`/`exec` wrapper,** which sends
  SIGALRM to the whole process. Same-thread timers and `vm` timeouts cannot
  interrupt synchronous host work. A suggested actual budget is 15 s against
  the 10 s in-process command deadline.
- **Heap.** The effective V8 heap is measured from `heap_size_limit`, and must
  be at most 134217728 B under `--max-old-space-size=125`. Flags alone are
  never trusted.
- **Unmeasured resources.** RSS, external, ArrayBuffer and address-space use
  are not measured or capped. The typed, work and mesh numbers are estimates
  that exclude JS objects, the VM, matrices, GC and copies.
- **Output streams.** stdout carries one bounded JSON line. stderr is not
  produced by design, and it is the caller's job to bound and collect both
  streams.
- **Cross-libm differences.** The tiny cases match exactly on this Mac. Any
  actual-model discrepancy must stay held, with no tolerance widening.
- **Signed zero.** The fixture's expected meshes contain no −0 lanes. Signed-zero
  sensitivity is covered by the bridge and SHA mutation tests, not by a
  reference case.
- **Overflow bound.** It is a conservative formula over the cap values, not a
  per-model analysis.
- **Source scope.** The structure check covers what the bridge reports. Source
  integrity rests on the closure SHA, not on runtime method comparison.

### Corrections

1. **Creation ownership.** `createRunDirectory` captures the prefix ancestry
   before `mkdir`, then the first post-create `lstat` of the new directory
   (dev/ino/mode/uid, 0700, own uid). It then captures a provisional full
   namespace. That namespace must equal both earlier observations. It is
   rechecked, and the directory must still be empty, before it becomes the
   trusted run authority. Any replacement after the first `lstat` refuses
   with `run_directory_ownership` before anything is written.
   **Boundary:** path-only `mkdir`/`lstat` cannot rule out a replacement
   made between `mkdir` and that first `lstat`. Node has no `openat`, so each
   later write is path-based: a swap between a namespace recheck and `open`
   is detected only by the post-write seal, not prevented.
2. **Ownership versus success authority.** `ownership()` rechecks only the
   trusted run namespace and does not depend on the deadline. It gates every
   write, every alias-retirement step and `failure.json`, even after the
   deadline has passed. `authority()` is ownership plus the deadline, every
   held input and the body. `writeExclusive` now rechecks the trusted parents
   rather than adopting whatever namespace the path names at that moment. If
   ownership is lost, `runObserver` returns `ownership_lost:true`,
   `failure_write_error:'run_directory_ownership_lost'` and a bounded
   `failure_summary`, and it writes nothing into the replacement tree.
3. **Exclusive dequalification.** `retireAlias` acts only on a `result.json`
   whose dev/ino match this run's linked candidate. It preserves the alias by
   `link` to the first free name among `result.unqualified.json` and
   `result.unqualified-1..7.json`. Occupied files or directories are
   recorded and never overwritten. Ownership and identity are rechecked
   before each `link`/`unlink`. A foreign final is reported as
   `foreign_final_untouched` and left byte-for-byte intact. An IO failure is
   reported as `status:'failed'` with `{during, code}` and is never described
   as retired. Foreign bytes are never deleted. The candidate file keeps the
   published bytes in all cases.
4. **Primary errors and sticky close diagnostics.** Held reads, output writes
   and readback (`withFd`), body cleanup and all-input cleanup now keep the
   primary error. A close fault becomes a `closeDiagnostics` entry
   `{during, code, message}` on the primary, or joins the run-level
   `close_errors`, and every remaining close is still attempted. A close
   fault with no primary error is an explicit `output_close` or
   `cleanup_failed`. Returned mesh, structure and body metadata are kept as
   soon as compile returns (`identity_post_matches:false` until the recheck
   passes), so a later failure still records them. Body bytes are never kept.
5. **Structure before lifecycle.** The model is constructed once in a
   structure phase. That phase bounds node and face counts, collects each
   node's sorted distinct observed `face.smoothGroup` values (integers 0..31,
   from the realm faces only), stores the model only as realm-owned
   `__geomState`, and returns a bounded primitive string. The host
   `validateStructure` matches it to the independent preflight, including
   `primary_smooth_groups`. Only then does a lifecycle script in the same
   realm take and delete `__geomState` and run the unchanged `hasAnimation`,
   `createInstance` and `compile`. A cleanup script clears
   `__geomState`/`__geomInput` on every path (success, mismatch, timeout),
   and the context reference is dropped. No host object or callback enters
   the realm. The intrinsic brand and extent getters, disabled codegen and
   the console deletion are unchanged. `realmStats.{definitions, structure,
   lifecycle}` count the phases.
6. **Dense placement.** Each position/rotation/scale lane must be an own data
   property holding a finite number. Holes, accessors and inherited lanes
   refuse before any VM is created. In the profile, `{"number":"-0"}` is
   restored only at rotation lane 0, and every other object-valued lane
   refuses.
7. **Float32 column admission.** `checkRoundedColumns` is adapted from Root's
   qualified `ROUNDED_COLUMNS.mjs` (3235 B, `648dfd4b…`) into the owned
   module, with no file dependency. It runs ZXY rotations with Float32
   destination stores, rounded scale and the [1,-1,1] flip. It requires
   finite, nonzero squared column lengths and finite normalizations, and it
   runs in `checkPlacement` before any VM. It has no epsilon, no scale floor
   and no tolerance widening.
8. **Held fixture.** The declared fixture is read once through the held
   descriptor (148023 B, `c3ad8c64…`) and fully hashed. It is parsed only to
   check its task and admission fields, recorded as `record.fixture`, and
   rechecked through final authority and close. A changed fixture refuses at
   stage `fixture` before the scaffold write and before any realm.

Retained unchanged: exact source closure, body grammar, numeric global mesh-key
order, eight names per declared list, the face-record cap, the pre-VM
result/resource estimate, the observation of the realm-copy SHA, intrinsic
Float32 brand/extents, the post-validation terminal deadline and every copied
client method (the closure SHA is checked in every test run). Shadowing a
