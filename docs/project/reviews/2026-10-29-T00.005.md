`model_constructor_worker.mjs`, even when writing identical bytes. Its header

verifier while leaving `git diff` clean. This is a confirmed source-level
hazard, not a report that Root executed that unsafe suite in this audit.

`TARGET_MODEL_CONSTRUCTORS.md:112–136`. **T00.006** must supply a checked-in
self-isolating path and interruption-preservation checks before this suite
is promoted into routine local/CI automation.
