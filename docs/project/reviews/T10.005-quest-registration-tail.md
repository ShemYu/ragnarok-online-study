## API

When appended at module scope, the tail is one closed `void function(){'use strict';…}()`
expression. It takes no parameters, has no CLI/options/exports and does no retry.

1. It reads `Object.getOwnPropertyDescriptor(globalThis, '__rootQuestRegistrationT10005')`.
   An existing own property throws synchronously. The getter is never read and
   the descriptor is left unchanged.
2. It creates a promise and defines the slot as nonwritable, nonenumerable and
   nonconfigurable. If the definition throws, the tail throws and no run starts.
3. It starts exactly one run. The promise resolves with the closed contract
   report, or rejects with an `Error` that carries `reasons` (latched codes),
   `diagnostic_complete:false` and `stage_count`.

Fixed IDs are the literals `[21001, 16912]`.

## Observation behaviour and limits

- **Delegate.** One non-async `observedLoader` is passed as `rFunc` and reused
  for the SystemEN and custom calls. Before forwarding it opens a stage, takes
  the `before` snapshot and swaps only argument 2 for an observational callback.
  It calls `Reflect.apply(loadQuestInfo, this, args)` exactly once and returns
  the result. If the loader throws, the identical object is rethrown and that
  invocation ends.
- **Callback wrapper.** It records an `after` snapshot and the aggregate, then
  forwards synchronously once per call with `Reflect.apply(forward, this,
  arguments)`. Return values and identical throws are preserved, and nothing is
  awaited. Duplicates are forwarded and latched as `duplicate-callback`, never
  suppressed. The text branch uses the same wrapper, with `terminal` as its
  forward target.
- **Callback summary.** Each callback records `argc` and `first_boolean`
  (`true`, `false` or `NOT_REPORTED`). A text success (`argc` 0) reports
  `NOT_REPORTED`. Other arguments, `this`, return values and throws are not
  captured.
- **Snapshots.** Snapshots are taken at initial (after startup, the lookups and
  custom admission, before the first dispatch), at each stage `before`, at each
  observed callback and at finalization. Each holds `Object.getOwnPropertyNames`
  as a count and a private key set, plus own-descriptor typed values for the
  two IDs only. The typed values are detached copies built at that instant.
  Accessor rows refuse, and getters are never invoked.
- **Aggregates.** These are own-key effects only: before/after counts and
  added/removed/retained from the key sets, and `fixed_changed` from canonical
  typed JSON. Same-key replacements, appends, unchanged reprocessing and
  registration call counts remain UNKNOWN.
- **Typed grammar.** The tail implements the contract grammar. Arrays keep
  holes, and extra or symbol keys refuse. Records must be ordinary or
  null-prototype with own data only, and keys are sorted by UTF-16 code unit.
  Cycles, functions, symbols, bigint and exotic objects refuse.
- **Caps.** Depth 8 (root is 1), 32768 nodes for the whole run (never reset),
  65536 code units per string or key, 65536 QuestInfo own keys, 41 stages, and
  32 custom paths of at most 1024 units with no NUL.
- **Report budget.** It is charged incrementally before each append: typed
  leaves and keys exactly, and fixed structure with conservative constants.
  Exact UTF-8 length is checked again on the final JSON (512 KiB cap).
- **Failures.** An observer failure is latched without throwing into the chain,
  later observation is skipped, and forwarding and fallback continue.
  Rejection happens only at genuine finalization. Pre-dispatch config, admission
  or snapshot failures reject before any loader call.
- **Completion.** At most one `Promise.resolve().then(finalize)` is queued, and
  only when terminal has been seen (or an original throw was observed),
  `pending === 0` and `depth === 0`. The finalizer checks eligibility again and
  waits if new work has appeared. A missing callback leaves the promise pending
  until Root's external deadline. A throw without a terminal latches
  `route-aborted`. The run says nothing about callbacks after finalization or
  about HTTP/job retirement.
- **UNKNOWN fields.** `main_quest_semantic_result`, `internal_execution_errors`,
  `registration_and_append_call_counts`, `producer_provenance` and
  `current_session_equivalence` are always the literal `UNKNOWN`.
