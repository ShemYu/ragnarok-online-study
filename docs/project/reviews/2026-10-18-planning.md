## Findings and integration decisions

1. **Preserve historical paths.** Claude proposed moving old docs into a legacy directory. That would break established relative links and obscure evidence provenance. Kept the files in place and added current-goal/historical banners at entry points.
2. **No reset-based routine rollback.** Claude proposed resetting a phase branch to an earlier tag alongside revert. The integrated workflow uses traceable local checkpoint commits and `git revert`, with dependency-aware verification. External app/database recovery is separate.
3. **Every task has a paired record.** Claude proposed skipping trivial paired tasks. The user requested testing both on each task. The task is the unit of comparison, not every shell command; all T00–T13 tasks require a paired record. Shared-state tasks can compare plans/rehearsals honestly rather than performing two unsafe live mutations.
4. **Samples do not fulfill “all.”** Claude's random sample proposal and Grok's final one-map/one-monster/one-NPC tour can help a pilot or user demonstration. They cannot certify the world/story. T06 inventories expected/present/loaded/exercised/verified entries; T12 accounts for every required entry and quest chain with an explicit method.
5. **Evidence provenance stays exact.** Grok wrote that the M1 Max, bounded search and no-install state were measured on its dispatch, although its report says it read project documents. Those were supplied coordinator observations. The final docs attribute them correctly and leave resource usage unmeasured.
6. **No invented episode inference.** An installer date, server commit or client-reported value alone is not complete episode support. T06/T07 require reconciled content evidence before a named contract is accepted.
7. **Chinese needs an actual pilot.** Presence of an encoding control does not prove Big5 rendering, macOS input or translated server dialogue. T05 tests each text surface and keeps client/server/launcher gaps separate.
8. **Feasibility has a bounded investigation path.** Neither an unknown translation duration nor a missing Chinese toggle proves impossibility. The plan first diagnoses compatibility and inventories gaps, then estimates remediation. No full translation schedule is claimed.
9. **Restore proof precedes risky mutation.** A copy of app/VM files, especially while services run, is not automatically a consistent backup. Establish and test a suitable isolated backup/restore procedure before existing user progress can be affected; qualify recovery again in P4.
10. **Approval follows actual scope.** Both proposals added broad future permission stops. The real current restriction is documentation-only work. Future work follows its actual task authorization and existing user decisions; routine authorized work does not acquire a blanket extra approval requirement from these proposals.
11. **Check dependencies in the integrated draft too.** Coordinator review caught a T02 contract that mixed asset acquisition with later runtime compatibility proof. Separated them to avoid a circular gate. T05 now permits bounded encoding/compatibility children before the later bulk-translation work, and empty T08–T11 workstreams require verified no-change reports rather than artificial changes.
