## API

```rust
pub fn read_ordered_archives(
    state: &std::path::Path,
    data_anchor: &std::path::Path,
    optional_archive_slots_present: bool,
) -> Result<Option<Vec<std::path::PathBuf>>, String>
```

- The function reads `state/asset-archives.list` and creates or writes nothing.
- A missing list, including a missing state directory, returns `Ok(None)` for both values of the optional-slot flag. The state directory is left uncreated.
- A present list with `optional_archive_slots_present == true` returns `Err` prefixed `optional-slot-conflict`. The vector is not returned. A valid five-path body and a non-list body both take this path.
- Every other present-list failure returns `Err`.
- Success returns `Ok(Some(canonical paths))` in list order. The data anchor stays at the index where the list placed it.

Present-list admission order:

1. `symlink_metadata`. `NotFound` is absence. Any other metadata error is `manifest-io`. A regular file passed as `state` produced this prefix in the fixture.
2. Optional-slot conflict when the path exists and the flag is true.
3. Symlink: `manifest-symlink`. Any other non-regular node: `manifest-nonregular`. Link count other than 1: `manifest-hardlink`. Length above 65536: `manifest-over-cap`.
4. Read-only open. Open failure: `manifest-unreadable`.
5. Finite identity from `std::os::unix::fs::MetadataExt`: device, inode, link count, length, `mtime`, and `mtime_nsec`. The opened descriptor, the path before the read, and the path after the read must all match. A short read or one extra byte is `manifest-identity-changed`.
6. Grammar, then one admission per path.

Grammar rejects, in order: NUL, CR, invalid UTF-8, a missing terminal LF, a blank line, a line count other than five, leading or trailing Unicode whitespace, and a line whose first character is `#`. Each remaining line must be absolute. Internal spaces stay. The reader does not trim or drop lines. A 65536-byte body passes the size gate and then fails grammar. A 65537-byte body fails `manifest-over-cap` before grammar.

Each entry is canonicalized, must be a regular file, and must open for reading. The descriptor is closed without reading archive bytes. Equal canonical paths return `entry-duplicate` before the anchor count, so a repeated anchor line is a duplicate. The canonical data anchor must occur once. An unresolved anchor uses `entry-missing-anchor` and contains `unresolved`. A resolved anchor missing from the five uses `entry-missing-anchor` and contains `absent-from-list`. A missing path is `entry-missing`, an unreadable path is `entry-unreadable`, and a directory is `entry-nonregular`. A canonical path that is not Unicode, or that contains CR, LF, or NUL, also uses `entry-nonregular`. The macOS fixtures did not produce that last path.

Under `cfg(test)`, one hook runs after the opened identity matches and before the bytes are read. A build without `--test` calls an empty function there. The test guard clears the hook on drop.
