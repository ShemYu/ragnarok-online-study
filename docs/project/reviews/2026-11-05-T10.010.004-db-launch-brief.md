## Minimal public API and file responsibilities

`restore_gate.py` exports only the necessary operation entry point:

`run_gate(spec, *, admit_sha256, pre_release)`

`spec` is a strict-schema dictionary with exactly these keys:
`schema`, `operation`, `operation_dir`, `launcher`, `observer_template`,
`interpreter`, `app`, `real_cli`, `host_input`, `cwd`, `environment_hex`,
`nebula_home`, `input_admission`. Use schema `root-restore-launch-spec/v1`.
Operation is1–80 ASCII alphanumeric/dot/underscore/hyphen characters; paths are
absolute physical paths. operation_dir must be absent (including no dangling
symlink) with an existing physical, owned, non-symlink parent; the parent is
authenticated and its identity rechecked when exclusively creating the0700
operation directory. Never create missing ancestor paths, adopt an existing
operation directory or reuse a refused/released operation. All other direct
input paths already exist and are authenticated. Each of launcher, observer_template, interpreter,
app, real_cli, host_input and input_admission is a pin with exactly
`path`, `bytes`, `sha256`; bytes is a nonnegative integer
(not bool), sha256 is64 lowercase hex. Runtime stat/physical/ownership
validation is additional. Runtime app/CLI must
match the observer's fixed runtime constants. Do not accept arbitrary runtime
argv: derive exactly `[app, 'restore', input, '--eras', 'renewal']`.

input_admission is an externally Root-qualified opaque receipt pinned by exact
path/size/hash. The helper authenticates its bytes and binds it in the manifest;
it does not infer SQL validity, fixture correctness, stage identity or semantic
restore authority by parsing its contents. A matching receipt pin is necessary,
not sufficient: Root's separately qualified pre_release supplies live authority.

Canonical spec bytes are exactly
`json.dumps(spec, sort_keys=True, separators=(',', ':'), ensure_ascii=True,
allow_nan=False).encode('ascii')`, with no trailing newline. Reject duplicate
JSON keys when loading; reject all fields/types outside this schema, floats,
NaN/Infinity, booleans in integer fields and unpaired Unicode surrogates. Do not
normalize strings or paths to make mismatches pass. `admit_sha256` is exactly
the lowercase SHA256 of those canonical bytes. The fresh runtime gate copy's
`RUNTIME_SPEC_SHA256` literal must equal both this hash and admit_sha256 before
any child or operation-file creation. An unset literal refuses; the function
argument cannot override it. Source pinning of this literal-bound module is a
separate Root authority, not a circular self-hash inside spec.

`environment_hex` is a list of two-element lists `[key_hex, value_hex]` encoding
exact POSIX key/value bytes. Hex is lowercase, even-length, no whitespace or
prefix; a value may be empty. Decode then require nonempty keys, no `=` in a
key and no NUL in either component. Require strict lexicographic ordering by
decoded key bytes, unique keys and exact lowercase re-encoding equality.
This is the complete admitted **base** environment vector, never an ambient merge.
Its JSON form is covered by the spec hash. Observer's environment digest is
separately computed from decoded bytes using observer.py49–56, not from JSON
or from a Unicode/locale conversion. Root must supply any deliberately admitted
OS-injected key explicitly; unknown additions or changed values refuse. Require
the base NEBULA_HOME bytes to equal the admitted nebula_home path bytes, so the
app selects that owned home. Derive app_env by setting/replacing only
RAGNAROKMAC_DOCKER with the future allocated observer path bytes; every other
key/value is unchanged. The permitted delta may be addition when that key was
absent. Keep this launch app_env immutable through READY and direct execve.

Derive a separately labeled supervisor_runtime_env by applying the pinned
Darwin config::widen_path() transformation exactly once after app entry.
For this bounded profile, require HOME present/nonempty, strict UTF-8, absolute
and lexically canonical: root `/` or slash-separated nonempty components with
no `.`/`..`, duplicate/trailing slash, colon or NUL. Require PATH absent or
strict UTF-8 without NUL; other admitted environment bytes remain unchanged.
Unsupported HOME/PATH representations refuse before Popen; do not silently
follow home()/join_paths fallbacks, consult ambient HOME or normalize input.
No HOME filesystem lookup or new spec key is needed.

Construct first prefix HOME joined with `.rd/bin` (root gives `/.rd/bin`),
then `/opt/homebrew/bin`, `/usr/local/bin`, `/opt/podman/bin`, followed by all
colon-separated components of the original PATH. Preserve order, duplicates
and empty components exactly. Missing PATH is treated as empty bytes by this
pinned source; splitting yields one empty component, so missing/empty PATH
produces the same final trailing colon. In this admitted no-colon HOME profile,
the resulting bytes are the four colon-joined prefixes + `:` + original PATH
(or empty bytes if absent). Set only PATH in supervisor_runtime_env.
The Rust Unix split/join implementation preserves these components.
[Rust Unix path splitting/joining source](https://raw.githubusercontent.com/rust-lang/rust/1.80.0/library/std/src/sys/pal/unix/os.rs).

Derive observer_env from supervisor_runtime_env by exactly docker.rs's two
overrides: NEBULA_HOME=nebula_home and
DOCKER_HOST=`unix://`+nebula_home+`/run/docker.sock`. No other key changes or
deletions are authorized. Bind distinct launch, supervisor-runtime and observer
environment digests/projection in the manifest. Validate string-to-byte
encoding exactly and reject encoding loss. Preloading PATH prefixes does not
make widening idempotent: native startup adds them again.

The mandatory callback is `pre_release(binding)`. binding is a plain strict
dictionary with exactly seven keys: schema (literal
`root-restore-pre-release/v1`), operation (the admitted string), launcher_pid
(actual integer >1, not bool), manifest_path (exact physical absolute string),
manifest_sha256 (64 lowercase hex), held_identity_sha256 (64 lowercase hex),
deadline_ns (positive integer, not bool). The hashes bind immutable final
manifest and retained canonical held-identity evidence. deadline_ns is the
absolute same-host time.monotonic_ns deadline fixed at READY+60s, never a
relative allowance recomputed by the callback. Require current monotonic_ns
strictly below it before calling, after return and immediately before release.
Return must be a plain dictionary with exactly those seven fields equal
byte/value-for-value to binding plus status equal to literal `pass`; reject
unknown/missing keys, wrong types, mutated input/echo, exception or late return.
Retain an independent immutable copy of the request for the comparison. Callback
has no authority to extend deadlines or change source/env/identity. It runs
synchronously under the specified bound; elapsed checks cannot preempt a stuck
callback, so Root must supply a bounded implementation. No default approving
callback or helper-provided Engine access. Its receipt only joins Root's
separately qualified checks; caller booleans alone are not live proof.

Return a structure containing the serializable final record and, if unsettled,
the live direct-child handle for the Root caller to retain. Persist bounded
private custody evidence even when returning a live handle. Result vocabulary:
`pre_release_refused`, `instrumented_app_completed`, `restore_unresolved`.
Never return `restore_qualified`, semantic PASS, or global cleanup authority.
`instrumented_app_completed` requires the complete mandatory held OS identity,
immutable direct same-PID exec protocol, exclusive unreaped actual-child custody
through the matching observer receipt join, and then exact child terminal app0.
This establishes only local instrumented completion. It is not independent
kernel post-exec image attestation, Engine transport/remote-exec completion,
staged/guest input identity or restored semantics.

`launcher.py` is a single-use local executable: authenticate bootstrap input,
report READY, wait, validate final GO/manifest, close control FDs, then direct
`os.execve` without spawning an app child. `controls.py` authors fake-only

under that custody, not universal race-free filesystem/process guarantees.

After RELEASE_ATTEMPTED, no automatic app/observer/group/DB/VM kill, stop, retry,
